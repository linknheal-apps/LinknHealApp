# Link & Heal

تطبيق للصحة النفسية بين الجلسات، يخدم المعالج والعميل.

## المكونات
- تطبيق العميل: iOS و Android (Capacitor)
- لوحة تحكم المعالج: ويب
- الخلفية: Supabase (PostgreSQL مع RLS)

## التقنيات
React + TypeScript + Vite + Tailwind + Capacitor

## التشغيل محلياً
1. `npm install`
2. انسخ `.env.example` إلى `.env.local` واملأ القيم
3. `npm run dev`

## التوثيق
كل ملفات التصميم والقرارات في فولدر `docs/`:
- `constitution.md` المبادئ الأساسية
- `spec.md` المتطلبات
- `plan.md` و `architecture.md` الخطة والمعمارية
- `tasks.md` المهام

## قواعد المشروع
- ممنوع أي بيانات عملاء حقيقية في الكود أو الاختبارات (بيانات تجريبية فقط).
- ممنوع رفع أي مفاتيح أو ملفات `.env`.
- أي تعديل في جداول بيانات العملاء لازم يتراجع عليه من ناحية الخصوصية (RLS).
