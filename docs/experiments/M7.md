# Problem M7: entries_update_own with check (true)

## Problem
Patch `.mutation/M7.patch` changes `entries_update_own` from:
```sql
create policy entries_update_own on public.entries
  for update to authenticated
  using (owner_id = (select auth.uid()))
  with check (owner_id = (select auth.uid()));
```
to:
```sql
create policy entries_update_own on public.entries
  for update to authenticated
  using (owner_id = (select auth.uid()))
  with check (true);
```
Status: SURVIVED.
